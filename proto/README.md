# magnetite-sync-proto

The protocol of Magnetite sync, shared by the browser and the
[magnetite-sync](https://github.com/magnetite-browser/magnetite-sync) server:
24-word sync codes, key derivation, signed requests, end-to-end encryption
with padding, and the API types. See `docs/design.md` in the repository.
