# Changelog

## 0.1.0 (unreleased)

First public release: protocol v2 (sync codes, signed requests, end-to-end
encryption with padding), open, closed (the default) or invite-only
registration, per-chain quotas and write limits, a cap on chains and a daily
budget of new ones, deletion of unused chains and of chains that never stored
anything, bounded admission and deadlines. Data in Postgres, shared by any
number of server processes. Container image, Helm chart and static Linux
binaries for amd64 and arm64.
